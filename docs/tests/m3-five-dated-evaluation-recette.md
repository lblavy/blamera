# Recette — cinq références datées, galerie conservée

M3-02-B-01, PC 0.5.1 disponible sur http://127.0.0.1:8501/.
Les détections du corpus personnel sont préparées ; recette utilisateur en attente.

1. Recharger la page. Dans Références, retrouver les sept photos et confirmations
   existantes. Dans Évaluation, vérifier le compteur de cinq références retenues
   sur sept disponibles. Les séances des cinq retenues sont déjà renseignées.
2. Garder le lot Calibration : quinze photos, avec l'identité attendue sur chaque
   carte. Trois ont un seul visage détecté, douze plusieurs. Les cibles restent
   non sélectionnées à la publication, même avec un seul candidat.
3. Choisir le visage de la personne attendue, puis Enregistrer ce visage. Le guide
   privé `pc/data/import-plans/evaluation-targets-a-confirmer.md` donne l'ordre dans
   chaque lot et précise le sujet du dossier pour les inconnus. Si le bon sujet
   manque dans les candidats, signaler le numéro d'image ; ne pas en choisir un
   autre pour pouvoir lancer le rapport.
4. Après confirmation des quinze cibles, Évaluer la calibration. Vérifier bons
   noms, inconnus, faux noms, incertains et scores de similarité. Une abstention
   ou un mauvais nom reste une observation à analyser, pas forcément un bug logiciel.
5. Recharger et revenir à Évaluation : choix / confirmations et rapport doivent
   être conservés. Signaler une erreur de parcours ou une lenteur notable.

Les quinze photos du Test final réservé restent de côté pour le moment. Aucune
nouvelle date n'est demandée pour les deux références exclues de cette variante.
Ce premier lot exploratoire ne démontre pas encore la fiabilité en population ;
la calibration, le gel des paramètres et le test indépendant restent ouverts.
