# Recette — clé visible et actions homogènes

Version 0.15.1/code29 installée le 1er novembre 2026 à 11:25, heure de Paris.
Parcours essentiel accepté par l'utilisateur : « ça a l'air ok ».
Revue et validations PC conformes ; diagnostics botaniques et ChatGPT confirmés.
Le protocole ci-dessous n'est pas une déclaration d'exécution individuelle de
chaque cas optionnel.

1. Ouvrir Configuration : le champ reste vide malgré la clé déjà enregistrée.
   Saisir quelques caractères d'essai sans enregistrer, toucher l'œil pour les
   afficher puis les masquer. Fermer et rouvrir : champ vide et masqué, clé
   enregistrée toujours configurée. Ne pas transmettre la clé dans le chat.
2. Vérifier que les trois boutons Analyser, ChatGPT et Lens ont le même style plein
   lorsqu'ils sont disponibles ; durant une opération, leur désactivation réelle
   doit rester lisible. Vérifier rapidement paysage et accès à la configuration.
3. Avec la clé existante, importer une image contenant une plante et d'autres
   objets. Attendre l'hypothèse puis toucher ChatGPT sans modifier le cadrage.
   Laisser l'application ouverte et le téléphone connecté pour lire uniquement
   les nouveaux événements techniques de Blamera.
4. Si souhaité, sélectionner un autre objet ou zoomer sans réanalyser puis toucher
   ChatGPT : une hypothèse du cadrage précédent ne doit pas être injectée. Ce cas
   complète l'indicateur technique, sans photo ni contenu de réponse à envoyer ici.

L'utilisateur lance et manipule l'application ; l'agent ne pilote pas le téléphone.
