## Avertissements, métriques et preuve appareil

- La première passe complète avait 8 tests verts mais lint échouait sur le `:` non échappé
  du chemin Windows dans `local.properties`. Le chemin local a été corrigé ; aucune baseline
  ni désactivation du contrôle n'a été ajoutée. Une icône adaptative a aussi été fournie.
- Lint final : **zéro erreur, 13 avertissements**. Dix concernent des versions plus récentes,
  choisies ici de façon cohérente avec SDK 36 ; les trois autres concernent les règles
  d'extraction/sauvegarde de données, le qualificateur d'icône v26 redondant avec minSdk 36 et
  l'icône monochrome optionnelle. À réexaminer lors de M0-03 ; aucun avertissement n'est masqué.
- Avertissement de lecture SDK XML v4 par un outil connaissant v3 ; build et tests passent,
  mais l'écart de génération SDK/AGP reste documenté et sera revu au besoin.
- Couverture, complexités, duplication, analyse de vulnérabilités et gates CI : **non mesurées
  ou non configurées à ce stade**, travail prévu en M0-03. Ne pas assimiler lint à tous ces contrôles.
- Dans ce sandbox, le premier téléchargement a échoué en DNS et un lancement Gradle n'a pas
  pu joindre son daemon local ; les commandes bornées ont été relancées avec l'escalade approuvée.
- L'installation du seul APK principal tentée par l'orchestrateur avec `adb install -r` a échoué,
  sortie 1 : `INSTALL_FAILED_USER_RESTRICTED` / `Install canceled by user`. Aucun lancement
  ou changement de réglage n'a été effectué ; la question de confirmation/installation manuelle
  a été transmise à l'utilisateur sans contourner la restriction.
- La deuxième tentative d'installation du seul APK principal, de même SHA-256 indiqué plus haut,
  avec `adb install -r` a réussi : sortie 0, `Success`.
- Après ouverture et choix Caméra/Image effectués manuellement, l'utilisateur confirme :
  « L’application s’ouvre et les deux choix fonctionnent ». Cette preuve couvre le lancement
  et les deux choix sur le Xiaomi ; la restauration d'état reste vérifiée sur PC seulement,
  sans prétendre à une validation réelle de rotation.
- Aucun réglage, lancement automatique, test APK, capture d'écran ou effacement sur téléphone
  n'a été effectué. La protection du téléphone reste applicable aux vérifications suivantes.
- La revue indépendante et la validation du tester sont conformes ; M0-02 est terminé.
